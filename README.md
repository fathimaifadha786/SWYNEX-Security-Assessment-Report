# SWYNEX Security Assessment Report

## Project Overview

This project was completed as part of the SWYNEX Cybersecurity Internship.

The main objective was to perform a defensive security assessment of the OWASP Juice Shop web application using the OWASP Top 10 categories.

## Tools Used

- OWASP Juice Shop
- Burp Suite Community Edition
- Browser Developer Tools
- Docker Desktop
- PowerShell

## Assessment Scope

The assessment covered the OWASP Top 10 categories from A01 to A10.

## Report

The complete Security Assessment Report is available in this repository as a PDF file.

## Key Learning Outcomes

- Understanding web application security.
- Testing access control and authentication.
- Identifying SQL injection indicators.
- Reviewing security misconfigurations.
- Understanding risk ratings and remediation recommendations.

## Disclaimer

All testing was performed in an authorized local lab environment for educational purposes.
